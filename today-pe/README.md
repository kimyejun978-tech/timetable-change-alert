# 오늘체육 MVP

체육 수업의 종목·장소·준비물을 교사가 등록하고 학생이 웹에서 바로 확인하는 모바일 우선 웹 프로토타입입니다.

## 현재 구현된 흐름

- 학생 / 교사 역할 선택
- NEIS 학교기본정보 API를 이용한 전국 학교 검색
- 학생: 학교 → 학년 → 반 초기 등록
- 학생: 오늘 체육 수업 확인
- 학생: 이번 주 체육 일정 확인
- 교사: 이름 / 관리 PIN 초기 설정
- 교사: 오늘 등록된 수업 목록 확인
- 교사: 날짜 / 교시 / 학년 / 반 / 종목 / 장소 / 준비물 / 안내 등록
- 교사: 쉼표 입력으로 여러 반에 같은 수업 일괄 등록
- 교사: 수업 수정 / 삭제
- 브라우저 재접속 시 설정 유지
- 모바일 반응형 UI

## 실행 방법

정적 웹이라 별도 빌드가 필요하지 않습니다.

1. 저장소를 내려받습니다.
2. `today-pe/index.html`을 Live Server 등으로 실행합니다.
3. 첫 화면에서 학생 또는 교사 역할을 선택합니다.
4. 학교명을 검색해 NEIS 결과에서 학교를 선택합니다.

> 브라우저의 `file://` 방식으로 직접 열 경우 환경에 따라 외부 API 호출이 제한될 수 있으므로 Live Server 사용을 권장합니다.

## 데이터 구조

현재 MVP는 서버 없이 시연할 수 있도록 브라우저 `LocalStorage`를 사용합니다.

- `oneulPe.profile.v1`: 현재 사용자의 역할, 학교, 학년/반 또는 교사 프로필
- `oneulPe.lessons.v1`: 등록된 체육 수업 데이터

학교는 다음 NEIS 식별자를 함께 저장합니다.

- `ATPT_OFCDC_SC_CODE`: 시도교육청 코드
- `SD_SCHUL_CODE`: 표준학교코드

두 값을 묶어 학교별 수업 데이터를 구분합니다.

## NEIS 학교 검색

`https://open.neis.go.kr/hub/schoolInfo`의 학교기본정보 API를 호출합니다.

현재 프로토타입에서는 학교명 검색에 필요한 최소 파라미터만 사용합니다.

- `Type=json`
- `pIndex=1`
- `pSize=30`
- `SCHUL_NM=<검색어>`

실서비스에서 API Key가 필요하거나 요청량이 늘어나는 경우, 키를 프론트엔드에 노출하지 않고 서버리스 함수나 백엔드 프록시를 통해 호출하는 구조로 바꾸는 것을 권장합니다.

## 중요한 제한사항

현재 버전은 **대회용 프론트엔드 MVP**입니다.

- 수업 데이터가 같은 브라우저에만 저장됩니다.
- 학생과 교사가 서로 다른 기기에서 실시간으로 공유할 수 없습니다.
- 교사 PIN은 실제 인증 수단이 아니며 로컬에 저장됩니다.
- 푸시 알림은 아직 구현하지 않았습니다.

즉, UX와 핵심 사용 흐름을 먼저 검증하기 위한 버전입니다.

## 대회 데모 시나리오

1. 학생이 학교 검색 → 학년/반 등록
2. 학생 화면에는 아직 수업 정보 없음
3. 설정 변경 → 교사 역할 선택
4. 같은 학교에서 `1학년 2반 / 5교시 / 축구 / 운동장 / 체육복` 등록
5. 다시 학생 역할로 전환해 오늘 체육 확인
6. 교사에서 `축구 / 운동장`을 `배드민턴 / 체육관`으로 수정
7. 학생 화면에서 변경된 결과 확인

실서비스에서는 학생/교사 전환 대신 서로 다른 기기에서 같은 서버 DB를 바라보게 됩니다.
