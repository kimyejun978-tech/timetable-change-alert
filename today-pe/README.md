# 오늘체육 MVP

체육 수업의 종목·장소·준비물을 교사가 등록하고 학생이 웹에서 바로 확인하는 모바일 우선 웹 프로토타입입니다.

## 현재 구현된 흐름

- 학생 / 교사 포털 분리
- NEIS 학교기본정보 API를 이용한 전국 학교 검색
- 학생: 학교 → 학년 → 반 초기 등록
- 학생: 오늘 체육 및 이번 주 체육 확인
- 교사: 별도 로그인 화면 및 세션 가드
- 교사: 여러 교사가 같은 학교에서 각자 수업 안내 등록
- 교사: 전체 수업 / 내 수업 필터
- 다른 교사가 등록한 수업은 조회만 가능
- 동일 학교·날짜·학년·반·교시 중복 등록 방지
- 교사: 학교 주소 기반 현재/오늘 날씨 표시
- 교사: 각 체육 교시의 시간대별 기온·강수확률 표시
- 교사: 오늘 학교 전체 체육 시간표 자동 조회
- 컴시간 시간표에서 바로 `안내 등록` 버튼으로 종목/장소/준비물 입력
- 모바일 반응형 UI

## 시간표 데이터 우선순위

시간표는 다음 순서로 조회합니다.

1. **컴시간알리미**
2. 컴시간 학교 검색 또는 조회 실패 시 **NEIS 고등학교 시간표 API**
3. 로컬 정적 개발 환경에서 서버리스 API를 사용할 수 없으면 브라우저에서 **NEIS 직접 fallback**

컴시간 쪽은 HTTPS 프론트엔드에서 직접 호출하지 않습니다. `api/timetable.js` 서버리스 함수가 `parse-comcigan`을 사용해 데이터를 읽고 프론트엔드에 정규화된 JSON을 반환합니다.

컴시간은 공식 공개 API가 아니라 비공식 파싱 방식에 의존하므로, 제공 방식이 바뀌면 해당 어댑터만 교체할 수 있도록 NEIS fallback을 분리해두었습니다.

## 교사 대시보드 데이터

### 학교 위치/날씨

학교 검색 단계에서 저장한 NEIS 도로명주소를 기반으로 위치를 찾습니다.

- 1차 위치 검색: OpenStreetMap Nominatim
- 2차 위치 검색: Open-Meteo Geocoding
- 날씨: Open-Meteo Forecast

컴시간에서 학교 일과시간을 받아온 경우 각 교시의 실제 시작시간을 날씨 매칭에 우선 사용합니다. 없으면 임시 기본 교시 시간을 사용합니다.

### 체육 시간표

컴시간에서 오늘 학교 전체 시간표를 읽고 다음 과목명을 체육으로 인식합니다.

- 체육
- 운동과 건강
- 스포츠 생활
- 스포츠
- 체육탐구 / 체육 탐구

각 행에는 학년·반·교시·과목·컴시간 담당교사·특별실·시간대 날씨를 표시합니다.

## 실행 방법

정적 학생/교사 화면만 확인하려면 Live Server로 `today-pe/index.html`을 실행할 수 있습니다.

컴시간 우선 서버리스 API까지 함께 확인하려면 Vercel 같은 Node 서버리스 환경에 배포해야 합니다.

```text
GET /api/timetable
  ?schoolName=학교명
  &region=지역
  &officeCode=NEIS교육청코드
  &schoolCode=NEIS학교코드
  &date=YYYYMMDD
```

응답의 `provider` 값은 다음 중 하나입니다.

- `comcigan`
- `neis`
- 브라우저 직접 fallback일 경우 프론트에서 `neis-direct`로 처리

## 현재 인증/DB 제한

교사/학생 화면은 분리되어 있고 교사 페이지에는 세션 가드가 적용되어 있지만, 아직 서버 인증이 아닌 프로토타입 단계입니다.

- 교사 프로필과 수업 안내는 아직 LocalStorage 사용
- 교사 로그인 세션은 SessionStorage 사용
- 서로 다른 기기 사이의 실시간 공유는 아직 없음
- 개발자 도구 수준의 변조까지 막는 진짜 권한 제어는 아직 없음

다음 단계에서 Supabase Auth + RLS로 전환합니다.

## 대회 데모 핵심 흐름

1. 학생이 전국 학교 검색 → 학년/반 설정
2. 교사는 별도 교사 포털 로그인
3. 교사 홈에서 학교 위치와 오늘 날씨 확인
4. 컴시간에서 자동으로 오늘 체육이 있는 반을 시간순으로 표시
5. 각 교시의 예상 기온/강수확률 확인
6. 교사가 해당 시간표 행에서 `안내 등록` → 실제 종목/장소/준비물 등록
7. 학생 화면에서 자신의 반 체육 안내 확인
8. 우천 시 교사가 운동장 수업을 체육관 수업으로 수정
