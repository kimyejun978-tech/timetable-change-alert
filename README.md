# 시간표 변경 알리미

시간표 변경 알리미는 기본 시간표와 오늘 시간표를 비교해서, 바뀐 수업을 한눈에 확인할 수 있도록 만드는 웹사이트입니다.

컴시간 알리미에서 오늘 시간표를 확인할 수는 있지만, 원래 시간표와 비교해서 어떤 수업이 바뀌었는지는 학생이 직접 확인해야 합니다.  
이 프로젝트는 그런 불편함을 줄이기 위해, 기본 시간표와 오늘 시간표를 비교하고 변경된 교시만 따로 보여주는 것을 목표로 합니다.

## 프로젝트 목적

이 웹사이트의 핵심 목적은 단순히 시간표를 보여주는 것이 아니라, 시간표에서 바뀐 부분만 빠르게 확인할 수 있게 하는 것입니다.

예를 들어 원래 3교시가 체육이었는데 오늘은 자습으로 바뀌었다면 다음과 같이 표시하는 방식입니다.

```text
3교시 체육 → 자습
```

변경된 수업이 없을 경우에는 시간표 변경이 없다는 안내 문구를 보여주는 방향으로 구현할 예정입니다.

## 주요 기능

현재 계획 중인 기능은 다음과 같습니다.

- 기본 시간표 확인
- 요일별 기본 시간표 설정
- 학교, 학년, 반 정보 설정
- 기본 시간표와 오늘 시간표 비교
- 변경된 교시 표시
- 변경된 수업이 없을 경우 안내 메시지 출력

## 현재 구현 상태

현재는 웹사이트의 기본 화면 구조와 CSS 디자인을 먼저 작성하고 있는 단계입니다.

구현된 내용은 다음과 같습니다.

- 홈 화면 작성
- 기본 시간표 설정 화면 작성
- 설정 화면 작성
- 비교 결과 화면 작성
- 공통 CSS 디자인 작성
- 네비게이션 메뉴 작성
- 버튼, 표, 입력창 디자인 작성

아직 JavaScript 기능은 본격적으로 구현되지 않았습니다.  
`data.js`와 `main.js` 파일은 만들어져 있지만, 시간표 데이터 저장이나 비교 기능은 이후에 작성할 예정입니다.

## 사용 기술

- HTML
- CSS
- JavaScript

```text
timetable-change-alert

│  ├─ basic.html
│  ├─ index.html

├─ js
│  ├─ data.js
│  └─ main.js

```

## 파일 설명

### `html/index.html`

홈 화면입니다.  
오늘 시간표 변경 요약, 학교/반 정보, 교시별 시간표 비교, 변경된 수업 목록을 보여주는 화면입니다.

### `html/basic.html`

기본 시간표 설정 화면입니다.  
월요일부터 금요일까지의 기본 시간표를 입력하는 화면으로 사용할 예정입니다.

### `html/settings.html`

설정 화면입니다.  
학교 이름, 학년, 반 정보를 설정하는 화면입니다.

### `html/result.html`

비교 결과 화면입니다.  
기본 시간표와 오늘 시간표를 비교한 뒤, 변경된 교시를 정리해서 보여주는 화면입니다.

### `css/style.css`

웹사이트의 전체 디자인을 담당하는 파일입니다.  
배경색, 헤더, 네비게이션, 섹션, 표, 버튼, 입력창 등의 스타일이 작성되어 있습니다.

### `js/data.js`

시간표 데이터를 관리하기 위해 만든 파일입니다.  
추후 요일별 기본 시간표 데이터나 오늘 시간표 데이터를 저장하는 역할로 사용할 예정입니다.

### `js/main.js`

웹사이트의 동작을 담당하기 위해 만든 파일입니다.  
추후 버튼 클릭, 시간표 비교, 결과 출력 등의 기능을 작성할 예정입니다.

## 화면 구성

### 1. 홈 화면

오늘 시간표 변경 내용을 한눈에 확인하는 첫 화면입니다.  
교시별 기본 시간표와 오늘 시간표를 비교해서 보여주고, 변경된 수업 목록을 간단히 확인할 수 있도록 구성합니다.

### 2. 기본 시간표 화면

월요일부터 금요일까지의 기본 시간표를 설정하는 화면입니다.  
저장된 기본 시간표는 오늘 시간표와 비교할 때 기준으로 사용됩니다.

### 3. 설정 화면

학교, 학년, 반 정보를 설정하는 화면입니다.  
이 정보는 시간표를 구분하는 기준으로 사용할 예정입니다.

### 4. 비교 결과 화면

기본 시간표와 오늘 시간표를 비교한 결과를 보여주는 화면입니다.  
변경된 교시만 따로 정리해서 사용자가 빠르게 확인할 수 있도록 합니다.

## 디자인 방향

전체적인 디자인은 깔끔하고 단순한 학교 생활 도구 느낌으로 구성합니다.

주로 사용하는 색상은 다음과 같습니다.

- 배경색: `#f7f8fa`
- 카드 / 헤더 색상: `#ffffff`
- 테두리 색상: `#e5e8eb`
- 기본 글자 색상: `#191f28`
- 보조 글자 색상: `#4e5968`
- 메인 파랑: `#3182f6`
- 진한 파랑: `#15468b`
- 변경 강조 색상: `#ff6b4a`

파란색은 버튼과 메뉴처럼 기본적인 동작 요소에 사용하고, 변경 사항이나 중요한 알림은 주황색 계열로 강조할 예정입니다.
