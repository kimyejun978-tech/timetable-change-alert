# 시간표 변경 알리미

원래 시간표와 오늘 시간표를 비교해서 변경된 수업을 알려주는 웹사이트입니다.

컴시간 알리미에서 오늘 시간표를 확인할 수는 있지만, 학생이 직접 원래 시간표와 비교해야 하는 불편함이 있습니다.  
이 프로젝트는 원래 시간표와 오늘 시간표를 비교하여 바뀐 교시만 한눈에 확인할 수 있도록 만드는 것을 목표로 합니다.

## 주요 기능

- 원래 시간표 확인
- 오늘 시간표 입력
- 원래 시간표와 오늘 시간표 비교
- 변경된 수업만 따로 표시
- 변경된 수업 개수 표시
- 변경된 수업이 없을 경우 안내 메시지 출력

## 사용 기술

- HTML
- CSS
- JavaScript

## 파일 구조

```text
timetable-change-alert
├─ index.html
├─ css
│  └─ style.css
├─ js
│  ├─ data.js
│  └─ main.js
├─ assets
│  └─ logo.png
└─ README.md
```

## 파일 설명

- `index.html` : 웹사이트의 기본 화면 구조를 담당합니다.
- `css/style.css` : 웹사이트의 디자인을 담당합니다.
- `js/data.js` : 기본 시간표 데이터를 관리합니다.
- `js/main.js` : 시간표 비교 기능과 화면 동작을 담당합니다.
- `assets/logo.png` : 웹사이트에 사용되는 이미지 파일입니다.

## 실행 방법

1. 이 저장소를 다운로드합니다.
2. `index.html` 파일을 브라우저에서 엽니다.
3. VS Code를 사용하는 경우 Live Server로 실행할 수 있습니다.

## 개발 예정 기능

- 요일별 기본 시간표 저장
- 오늘 시간표 직접 입력
- 변경된 수업 강조 표시
- 모바일 화면 최적화
- 다크 모드
